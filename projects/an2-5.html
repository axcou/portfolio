SAÉ 4.EMS.01 - Expliquer ou prédire une variable quantitative à partir de plusieurs facteurs

Python Régression multiple Diagnostics Data Mining

Objectif

Dans le cadre du projet Data Mining sur les émissions mondiales de CO₂ (OWID + EDGAR, 218 pays, 2013-2022), construire un modèle de régression linéaire multiple pour expliquer le CO₂ par habitant à partir de variables intensives - et quantifier ce que le PIB seul ne capture pas. Projet réalisé avec Ibrahim Benkherfellah et Nathan Ruelle.

Ce que j'ai fait

  • Calculé les corrélations bivariées entre CO₂/hab et 15 variables intensives candidates ; variable la plus corrélée : PIB/hab (r = 0,746, R² = 0,556)
  • Sélectionné les variables par critère R² ajusté (pénalise la complexité) - comparaison de modèles à 2, 5 et 6 variables
  • Ajusté le modèle final à 6 variables : PIB/hab, part charbon, CH₄ fugitif/hab, CH₄ déchets/hab, F-gaz industriels/hab, intensité énergétique
  • Diagnostics complets : test F (F(6,157) = 150,00, p < 1,11e-16), Durbin-Watson ≈ 2,07 (pas d'autocorrélation), Shapiro-Wilk (normalité rejetée mais acceptable pour n=164)
  • Vérifié la couverture des intervalles : IC 95 % -> 39,6 % des observations, IP 95 % -> 95,1 %

Résultat obtenu

  • Modèle final : R² = 0,852, R²_ajusté = 0,846 - gain de +29,5 points par rapport au PIB seul (0,556)
  • Équation : ŷ = -1,20 + 0,0001×PIB/hab + 3,46×Part charbon + 1,11×CH₄ fugitif + 0,67×CH₄ déchets + 3,44×F-gaz industriels
  • Le charbon est le prédicteur au coefficient le plus fort (3,46) - invisible en bivarié simple, déterminant une fois les autres variables contrôlées
  • Interprétation : à iso-PIB, les choix de mix énergétique expliquent 30 % de variance supplémentaire sur les émissions

Compétences mobilisées

  • Sélection de variables par R² ajusté, analyse de la corrélation bivariée comme point de départ
  • Régression linéaire multiple sous Python (scipy, sklearn)
  • Diagnostics complets : test F, Durbin-Watson, Shapiro-Wilk, intervalles de confiance vs de prédiction
  • Interprétation des coefficients "toutes choses égales par ailleurs" dans un contexte multidimensionnel

Difficultés rencontrées

  • Les variables brutes (CO₂_charbon, CO₂_pétrole...) sont des composantes additives du total - les utiliser directement crée une multicolinéarité mécanique ; passer aux variables intensives (parts, ratios) a résolu le problème
  • Le charbon a une faible corrélation bivariée avec CO₂/hab mais un coefficient fort en régression multiple - comprendre pourquoi (effet de masquage par le PIB) a été le principal travail d'interprétation

Ce que j'en retiens

La corrélation bivariée donne une première image, jamais la vraie. Le charbon semblait peu lié aux émissions par habitant jusqu'à ce qu'on contrôle le niveau de développement - là, il devient le prédicteur le plus fort. C'est exactement ce que la régression multiple permet : isoler l'effet d'une variable en maintenant les autres constantes. Cela change radicalement les conclusions qu'on tire des données.
