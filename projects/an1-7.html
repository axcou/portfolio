SAÉ 2.01 - Conception et implémentation d'une base de données

SQL MCD PostgreSQL Modélisation

Objectif

À partir de deux jeux de données CSV sur les échanges de technologies bas carbone, concevoir un schéma relationnel complet, créer la base SQL, la peupler efficacement, puis en extraire des analyses pertinentes via des requêtes.

Ce que j'ai fait

  • Analyse des données sources et regroupement des attributs clés
  • Modélisation d'un schéma EA optimisé avec une association réflexive
  • Construction du schéma relationnel en respectant la normalisation jusqu'en BCNF
  • Création des tables SQL et import des données via des tables temporaires
  • Transformation des colonnes d'années en lignes avec UNNEST()
  • Rédaction de requêtes pour alimenter un tableau de bord dans Metabase

Résultat obtenu

  • Une base de données relationnelle optimisée, peuplée à partir de données brutes CSV
  • Plusieurs visualisations dans un tableau de bord Metabase : part des échanges bilatéraux vs nationaux dans le monde, rôle central de la Chine dans les exports en 2021
  • Scripts SQL vérifiés, efficaces et réutilisables

Compétences mobilisées

  • Conception de base de données (modèle EA, relationnel, normalisation jusqu'en BCNF)
  • Écriture de scripts SQL complets (création, peuplement, jointures, requêtes avancées)
  • Manipulation de données via UNNEST() pour gérer des structures non adaptées
  • Résolution de problèmes liés aux formats complexes (transformation colonnes années -> lignes)
  • Utilisation d'un outil de visualisation externe (Metabase)

Difficultés rencontrées

  • Certaines règles métier du cahier des charges étaient ambiguës et impliquaient des choix de modélisation (association ternaire vs. entité intermédiaire) : j'ai documenté les hypothèses retenues et leurs conséquences
  • L'alimentation de la base avec les fichiers fournis a révélé des incohérences dans les données sources (valeurs manquantes, doublons) qu'il a fallu gérer avant l'insertion

Ce que j'en retiens

Ce projet m'a permis de comprendre concrètement comment concevoir et structurer une base de données pour l'analyse. J'ai aussi découvert l'intérêt de bien préparer les données en amont, de choisir une modélisation adaptée et d'utiliser des requêtes performantes pour interroger efficacement de grands volumes. C'est une expérience directement liée aux missions d'un data engineer, et cela m'a encore plus motivé à me spécialiser dans ce domaine.
